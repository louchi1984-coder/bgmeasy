# 技法实测笔记（二胡、竹笛）

来自一次实际渲染，不是演奏资料；资料卡见 instrument-performance.md。

## 二胡：哪些是真的，哪些是音符模拟
- **真实发出**：`params.bend`（从下方滑入的半音数）和 `params.vibrato`（揉弦的频率变化比例，如 0.009），通过 MIDI 弯音实现，范围 ±2 半音，只能单音。
- **限制**：同一声部里所有音共用同一组参数。要在一首里既有揉弦长音、又有滑入、又有干净的短音，就拆成多个声部（例如 `erhu_vib`、`erhu_slide`、`erhu_plain`，用同一个 DSK ERHU 预设 `dsk-asian-dreamz:0:4`），各管几个小节。
- **音符模拟**：跳弓（断开重复音）、颤音（相邻两音快速交替）、倚音（极短的前置音）。这些只是短音符序列，不是真实弓法。
- 弯音只改音高，采样音色不变，没有弓弦质感或力度的变化。

## 竹笛
- 后端不发送弯音、CC1、连奏或换气控制。吐音、颤音、花舌、滑音、打音、叠音都只能写成短音符序列的近似。
- 实音音区须注明笛种/调性：香港中乐团图表人工读谱换算，C调曲笛常规G4–G6（另标A6/B6极限音）、G调梆笛D5–D7、G调新笛/大笛D4–D6。图中梆笛/曲笛要换算高八度，新笛/大笛按实音；详见 [音域核查](instrument-range-evidence.md)。图表不是所有型号的绝对极限，数值换算尚无第二位读谱者独立复核。
- 撤下“A4附近就暗、虚、不像笛子”的通则：A4在上述C调曲笛低音区范围内，音色与自然感还取决于实际笛种、演奏、采样和编配。原笔记的BAN-DI/GM Flute在C4–E7可出声及高区较响记录，仅作特定预设的技术观察，不认证真实竹笛音域或自然感。
- 音色：GM Flute（program 73）是西洋长笛预设；DSK保留原名BAN-DI，具体身份待核（见 instruments.json 的 `unverified-wind`），不能由名称认定为梆笛。选择竹笛音域参照不改变上述音源身份，交付时如实说明近似。
- 古筝等伴奏与笛子同音区时会遮盖笛子；笛子独奏时伴奏尽量稀疏、gain 压低。

## 写谱前自检
- `python3 -I scripts/check_ranges.py score.json` 查音区；二胡最低音 D4，低于它会被标 CHECK。
- `--report-levels` 查各层实际贡献。
