## 接入skill时应采用的方式

1. 数值与型号/定弦绑定，分别保存实音范围、图示附加音、缺音和证据位置；不把一个型号的范围套到整个家族。
2. 没有直接依据的“舒适音区”继续待核。来源只给总范围时，不据此上调整行confidence，也不填造common。
3. 竖笛、阮、笛、箏、簧风琴等须先确认具体类型；类型不明时，检查器应给条件提示，不能据一组未核数字判定不合常理。
4. 采样映射范围与真实乐器范围分别检查；GM名称、预设可出声和样本移调范围都不是演奏资料。
5. 对低音区“暗/虚”、高音区“尖”等判断注明来源和音源条件；数值音区检查不能验收自然感。

## 检索及谱面使用

```bash
python3 -I scripts/check_ranges.py --list-variants dizi
python3 -I scripts/check_ranges.py score.json
```

在适用声部写可选 `"range_variant": "dizi.hkco-qudi-c"`。这是演奏参照，不认证预设身份，也不改变渲染。未指定型号显示条件提示；选择图示/实用范围后，范围外只表示需要复核，不能推出不可演奏。明确的物理键盘边界与特定型号缺音会标CHECK。一般音域区间也不保证全部半音、快速变化或真实技法可用。
