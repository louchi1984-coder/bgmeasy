# 动机与乐句范式（旋律怎么写）

证据索引：[theory-evidence.md](theory-evidence.md)。定义与作者指导见 M01/M02/M04/M06–M08；质量检查和写作顺序是**项目归纳**，全部音符、结构和轮廓例子为**自编、未核听**（M03/M05），不是教材原谱。

做法：先按 [music-design.md 第0节](music-design.md#0-确定时长后先规划全曲) 确定覆盖全曲的方案（用户约定 G06），再在其中组织素材、贯通全长草图并细化编配。下列音符例子只演示手法，不是可直接移调套用的成品模板；多数例子为4/4。

## 1. 动机是什么

动机是可辨认、可发展的音乐材料，可以很短，也可以跨小节。**不以音数或音符密度衡量质量，不再默认“3~6个音、音越少越好”。** 少音、慢速、安静都需要具体的音乐身份。

区分三个层次：
- **动机/素材单元**：可辨认的节奏、音程或音型，可直接呈示，也可从较长旋律中提取，记录在`design.motif`。
- **基本乐思**：能作为呈示和重复单位的材料，可能一两小节，也可伸缩；不以它是否已经变形判断是否成立。
- **乐句与乐段**：材料在时间中形成的较大关系；乐句有可感知的方向与到达/停顿，乐段可以包含多个乐句。主题可由这些关系建立，不等于一个必须落主音的单元。

### 1a. 素材检查：先看身份与用途（项目归纳 M03，非质量量表）

新增创作素材先检查下列问题，记录具体音符/拍位依据。节奏与音高可以一项突出、一项克制，不强制两者都复杂：

| 维度 | 要回答的问题 | 需要进一步判断的情况 |
|---|---|---|
| 节奏身份 | 哪个起音、重音、长短关系或休止构成记忆点？为什么适合本次情绪？ | 只写“长短对比、节奏好记”，无法指到实际拍位；无法说明该节奏在当前乐句中的作用 |
| 音高身份 | 哪个音程关系、轮廓转折、重拍音或张力/解决值得保留？ | 仅以音阶/分解和弦名称声称有身份，未考察其在整句中的重音、去向与配合 |
| 方向与用途 | 这段材料呈现什么情绪，留下什么延续空间？由选定乐器怎样演奏？ | 只因“大调治愈、小调悲伤”就采用；材料与情绪、演奏动作没有实际联系 |
| 发展潜力 | 保留哪个识别核心，怎样形成不同的延续或回答？ | 只列变法或重复次数，未说明何处保持、何处继续/回答，以及音乐为何停留或前进 |

**先在整句与编配语境中判断素材是否有作用，再决定保持、重配或改写。** 少音、普通音程与原样重复都可以成立；也不能仅凭“简洁”免去对方向、重音和前后关系的检查。不靠加音、装饰或强制新奇凑质量。

### 1b. 在全曲方案内完成主题与延续

短主题、和声、节奏或音色试句可帮助形成方案（G01）。正式写谱时，以主题为核心的作品先贯通全长旋律与关键和声、节奏的草图；按全曲目标检查各句怎样衔接，再细化配器。律动/纹理型同样规划全长的保持或变化，不强制歌曲式主题，也不预设4或8小节。

**先让听众能建立材料的身份，再决定保持或变化。** 动机可以直接陈述、原样重复，也可融入较长主题；没有“首次出现必须发展”或“每小节必须变形”的要求。重复可确认记忆、延长停留或形成固定音型；变化可延续、回答或转向。检查这些功能是否在实际谱面成立，不按变法或重复次数验收。

例如素材`A4:1.5 F#4:.5 E4:2`只改成`A4:1.5 F#4:.5 E4:1 F#4:.5 r:.5`，只证明做了换尾/回转。若整段接着按同一格子逐和弦移动，需判断它是在建立固定型、保持身份还是无目的拼接，再决定是否改写。这个例子不证明三音素材普遍无效，也不要求所有主题增加音数。

固定音型用于低音、伴奏或纹理时可以重复；须说明其识别核心、重复的作用、与和声/其他声部的关系。不能把尚未写好的主旋律改名为“氛围纹理”绕过要求。用户明确要求的极简、固定循环或原样保留的主题/哼唱优先，不因这条规则擅改用户素材。

下面的**教学种子**M（C大调）只用于比较变化手法：
`E4:1 G4:.5 A4:.5 G4:2`
它只演示手法，不是默认成品主题；是否成立需结合完整乐句与本次情绪。

## 2. 变化手法（把一个动机扩成一段）

| 手法 | 做法 | 例子（基于 M） |
|---|---|---|
| 原样重复 | 可呈示/确认身份、延长停留或构成固定型；其作用在上下文中判断 | `E4:1 G4:.5 A4:.5 G4:2` |
| 换尾 | 开头保持、末端改变；本项目手法示例 | `E4:1 G4:.5 A4:.5 C5:2` |
| 模进 | 按音程/音级关系移位；此例为调内移位，不保证推进感 | `F4:1 A4:.5 B4:.5 A4:2` |
| 同节奏换音 | 节奏照旧，音换掉 | `D4:1 E4:.5 G4:.5 E4:2` |
| 同音换节奏 | 音照旧，节奏换 | `E4:.5 G4:.5 A4:1 G4:1 r:1` |
| 调性倒影 | 反转走向并适应调内音；此例不是精确半音镜像 | `E4:1 C4:.5 B3:.5 C4:2` |
| 逆行 | 逆序排列材料；是否采用按句法目标判断 | `G4:2 A4:.5 G4:.5 E4:1` |
| 增值 | 此例各时值加倍，占2小节；效果取决于上下文 | `E4:2 G4:1 A4:1` + `G4:4` |
| 减值 | 此例原材料时值减半，另加休止补满小节；休止不是减值定义的一部分 | `E4:.5 G4:.25 A4:.25 G4:1 r:2` |
| 截取并延长末音 | 取原材料片段，另改变末音时值；不是单纯截取 | `G4:.5 A4:.5 G4:3` |
| 装饰 | 加经过音、倚音 | `E4:.75 F4:.25 G4:.5 A4:.5 G4:.5 F4:.25 E4:.25 G4:1` |
| 升八度 | 改变音区与强调，可用于再现/推进，单独不证明高潮 | `E5:1 G5:.5 A5:.5 G5:2` |

组合时先确定每句的功能，再选手段。“原样+换尾+模进+落定”的排列不保证乐句成立；检查相邻小节是否真正延续、回答或解决，而不是四个相似格子的拼接。

## 3. 完整乐句：先确定期待与到达

从全曲方案中的连接与落点出发，问“前句留下什么、这句为什么接上、下一步及全曲最终去哪里”。据此选择保持、延续、回应或对比，再将旋律目标、和声、低音及节奏落点写成实际事件。记录 `design.phrases`（格式见 score-format.md），按前后句连起来复核；只有“这里发展、那里回应”的说明不足以证明谱面成立。以下均可伸缩，纹理型不强套主题曲式。

### 一个八小节的组织示例

C 大调、4/4；这是未核听的结构教学谱，不是交付模板。前两小节陈述一个乐思，第三四小节原样确认；后四小节用相关节奏片段连接到终止。

| 小节 | 和弦 | 旋律 | 作用 |
|---|---|---|---|
| 1 | C | `r:.5 E4:.5 G4:1 A4:.5 G4:.5 E4:1` | 弱起感、长短关系与回落建立身份 |
| 2 | C | `D4:1 E4:.5 G4:.5 E4:1 C4:1` | 接续并暂时停留；单个主音不等于完整终止 |
| 3 | C | 与第 1 小节相同 | 确认材料，不急于变形 |
| 4 | C | 与第 2 小节相同 | 保持呈示功能 |
| 5 | Dm/F | `F4:1 A4:.5 G4:.5 F4:1 E4:1` | 提取长短关系并开始向后连接 |
| 6 | G7 | `D4:1 G4:.5 F4:.5 E4:1 D4:1` | E 向 D 的连接结合属和声形成去向 |
| 7 | G7 | `F4:1 E4:.5 D4:.5 B3:1 D4:1` | 延续并准备终止 |
| 8 | C | `E4:1 D4:1 C4:2` | 旋律与和声共同到达 |

改变第 5–8 小节的和声时长、目标音或句长，会改变整体去向；只给第 3 小节换一个尾音并不能独自保证发展。反过来，前四小节原样重复也不构成缺陷。伴奏需沿共同节奏支撑和声连接，不跟随每个旋律音重新起和弦。

### 可选的组织方式

#### 结构 A：陈述—确认—延续—收束
| 位置 | 功能 | 必须落实的关系 |
|---|---|---|
| 开头 | 陈述基本乐思 | 让听众有机会认识材料 |
| 随后 | 原样/变化重复或回答 | 决定需要确认、停留还是改变去向，不强制变形 |
| 中后段 | 延续、对比或适度展开 | 解释音型为何被截取、连接、扩展或转向；不强制加密/升高 |
| 句末 | 收束或循环连接 | 让落点、句长、休止与前文形成可理解的结果 |

位置不强制一格一小节，可跨小节组织。先检验音乐关系，再决定具体长度。

#### 结构 B：前后句（前句较开放，后句较闭合）
- 结合和声、节奏、旋律和停顿建立前后句的相对结束感，不要求前句上扬、后句下行。
- 例如前句停在属和声，后句回到主和声；前后可共享相同开头，句末变化服务于不同落点。末音并非只能是主音。

#### 结构 C：呈示—保持/变化—对比—再现（长度按需要）
- A：陈述主题
- A 或 A'：确认身份，或改变延续方向/回答落点
- B：按情绪需要对比音区、节奏或和声，不默认更高更密
- A 或 A'：回到基本句关系并完成收束

#### 结构 D：循环（ostinato，用于需要持续音型的场景）
- 先判断该音型承担前景、伴奏还是纹理；按1a审查其身份，不因用途是BGM就降低素材要求。
- 固定音型可保持不变，其和声、配器或结构功能须明确；变化服从`design.arc`，不默认加密、加层或升高。
- 例：`E4:.5 G4:.5 A4:.5 G4:.5 E4:.5 G4:.5 A4:1`（每小节相同）
- 可用于追逐、科技、产品演示；不能把这个占位例子的移调循环当作默认成品主题。

#### 结构 E：逐步展开
自编候选：动机 → 模进 → 再模进 → 拉长 → 回落。这只描述操作顺序，不能据此证明形成高潮或充分发展（M05）。

## 4. 旋律轮廓（整句的形状）

**项目归纳 M05**：可试拱形、阶梯上行、下行、波浪、同音重复或大跳回落。只记录形状及其在本句中的作用，不把它们固定对应为悲伤、悠闲、焦虑或热血。相同轮廓可随和声、节奏、音区与演奏产生不同关系，实际效果待核听。

## 5. 目标音、张力与连接

1. 先找句内重要落点及其和声，再组织连接。和弦音可形成支点，倚音/延留等可在强拍产生张力；检查前后去向，而不要求每小节首拍落和弦音。
2. 经过、邻接、半音连接等按音高关系、拍位、时长与风格判断；调外音比例不是质量门槛。
3. 区分调式音级与当前和弦内的音程：C 大调的 A 在 F 和弦上是三音，G 在 Am7 上是七音。局部协和不自动等于整句终止。
4. 结束结合前后和声、低音、节奏和旋律；主和弦三音/五音可结束，开放衔接或循环无需强行落主音。
5. 音区和呼吸按实际乐器、句法与对白需要判断；连断、音长和重心也能分句，不按每两小节或休止百分比规定。当前后端不支持的连奏/延音线等不可仅写在设计说明中当作已实现。

## 6. 风格与写法的边界

撤下未逐项验证的风格—音阶—轮廓对应表（O06）；不凭“日系、温暖、武侠”等名字指定旋律音级或句式。用户对本项目中国风的约定见 O07；其余按本次意图、参考资料和实际音源写作。

## 7. 用现有字段记录全曲方案及谱面依据

复用 `design` 简记全曲方案，试写后更新为实际位置、音符和声部关系；不要求另建表格或固定篇幅。以下是记录用途示意，不是曲式模板，渲染器忽略这些注释：
```json
"design": {
  "mood": "得意、拽",
  "progression": "C小调：i–VI–iv–V (Cm Ab Fm G)",
  "motif": "填写实际素材的音高、时值与休止；可用 | 分隔小节",
  "motif_review": {
    "role": "前景主题（或伴奏固定音型/纹理；明确实际职能）",
    "identity": "指出实际节奏拍位/音程轮廓及其情绪作用，不能只写简洁好记",
    "phrase_plan": "标明主要乐句范围、与前句的关系、下一步及全曲目标，以及实际怎样通过音符和声部配合实现"
  },
  "structure": "覆盖全长的范围与职能；各部分为何相接，核心材料怎样贯穿，最后去哪里",
  "ending": "所选结尾功能及旋律、低音、和声、节奏怎样共同实现"
}
```
记录用于帮助写谱与复核，不代替乐谱或听感判断。局部调整涉及全曲关系时同步更新计划；旧谱缺少这些记录仍可渲染，格式和原脚本行为不变。

## 8. 自检清单（渲染前对照）

- [ ] 方案与草图是否覆盖全长，局部修改后整体去向是否仍成立？
- [ ] 主要连接处能否用实际音符、拍位与声部关系回答“前句留下什么—此句为何承接—最终去哪里”？
- [ ] 核心材料的身份、保持、重复或变化是否服务整体用途，而非仅列变法或凑长度？简约/循环也按实际职能检查。
- [ ] 旋律、和声/低音、共同重音与伴奏是否一起支持连接和落点？张力音的接近、离开或保持是否有作用？
- [ ] 句长、连断、音区与演奏是否适合具体音源，并由当前后端实际实现？
- [ ] 全曲结尾或循环接缝是否与前文相承？实际核听状态是否如实记录，未用字段与数值替代听感？

## 局限

这些范式是起点，不是好听保证。`check_melody.py`只能提供音高、时值与素材关系线索；节奏匹配、首拍落和弦音、记录完整都不能证明素材有辨识度或发展充分。按谱面审查并在能实际核听时核听；无法核听就保留“未核听”，不把技术报告写成听感合格。

定义与适用范围统一见 [theory-evidence.md](theory-evidence.md) M01–M09；八小节示例参考 T02 的组织概念，具体音符为本项目自编，不是对该教材原谱的引用。
