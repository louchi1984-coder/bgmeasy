# 和声候选、和声节奏与声部连接

证据索引：[theory-evidence.md](theory-evidence.md) H01–H05、M07/M08。术语有资料依据；以下进行、排列和选择步骤为**项目归纳／自编例子、未核听**，不承诺情绪、风格或质量。

## 1. 先说明级数的参照（资料·定义 H01）

罗马数字在指定调内表示根音级数，大小写区分大小三和弦，°表示减三和弦。C大调：I=C、ii=Dm、iii=Em、IV=F、V=G、vi=Am、vii°=Bdim。

A自然小调若以小调主音为1：i=Am、ii°=Bdim、III=C、iv=Dm、v=Em、VI=F、VII=G。和声小调的升高第7级可产生V=E与vii°=G#dim；不要把VII与vii°混用。此处III/VI/VII是相对小调音阶的级数标签；有些流行分析以同主音大调参照写♭III/♭VI/♭VII，须说明体系。

用户口头说“4536”时，可先明确是否指大调IV–V–iii–vi；不要把和弦编号当作主旋律音符。换调须保持或有意改变音程、和弦性质与调式条件，不能只替换数字而省略性质。

## 2. 进行候选（项目归纳 H04）

撤下“万能、史诗、冷感科技、任何结尾”等效果保证，及未核实的流派命名。下面仅给可试的顺序，均未指定时长、声部排列、旋律与奏法。

| 参照 | 级数 | 具体和弦 |
|---|---|---|
| C大调 | I–V–vi–IV | C G Am F |
| C大调 | I–vi–IV–V | C Am F G |
| C大调 | I–V–vi–iii–IV–I–IV–V | C G Am Em F C F G |
| C大调 | IV–V–iii–vi | F G Em Am |
| C大调 | IV–V–iii–vi–ii–V–I | F G Em Am Dm G C |
| C大调 | ii–V–I | Dm G C |
| C大调 | I–vi–ii–V | C Am Dm G |
| C大调 | I–IV–V–IV | C F G F |
| C大调 | IV–I 或 I–IV | F C 或 C F |
| A小调 | i–VI–III–VII | Am F C G |
| A小调，使用大V | i–VII–VI–V | Am G F E |
| A小调，使用大V | i–iv–i–V | Am Dm Am E |
| A小调 | i–VII–VI–VII 或 i–VI–VII | Am G F G 或 Am F G |

同一组顺序可以有不同风格与情绪；三和弦ii–V–I本身不保证爵士感，IV–I本身也不保证任意语境下的结束感。需要风格依据时查对应参考作品与专门资料，不把本表当作历史或流派认证。

## 3. 顺序、时间、低音与各线条一起判断

- **资料·定义 H02**：和声节奏是和弦持续与变化的时间组织，可在小节内变化或跨小节保持；不是BPM的同义词。
- **资料·指导 H03**：调性声部连接常考察共同音与经济移动；独立线条、重音与上下文也重要。四部习题中的规则不能直接成为摇滚、电子或平行和弦的普遍禁令。
- **项目归纳 H04**：按本句的停留、离开、积累和落点选顺序与时长，再试根音/转位/持续低音，连接内声部。可采用有意跳进、同向或反向活动，不自动追求最短距离。
- **资料·定义 M07/M08、H05**：调式音级、当前和弦内音程、整句的结束感分别判断。强拍非和弦音可有作用；不能只因是异音便叫倚音，需核对接近与离开。
- **项目归纳**：闭合、开放、循环或强击结尾按任务选择；不统一补主和弦或独立收尾小节。换和弦须核对功能、共同音与导向，不机械使用1↔6等替代。

`design.harmony`记录意图；`design.chords`只供检查，必须把实际音符写入sections。注释不会自动生成或改变声音。
