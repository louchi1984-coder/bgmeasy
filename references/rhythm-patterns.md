# 节奏概念与自编拍位候选

证据索引：[theory-evidence.md](theory-evidence.md) R01–R05。拍子与摇摆概念有资料依据；本页所有鼓型、旋律节奏和低音例子都是**项目自编、未核听**，不是权威流派范本，也不是情绪保证。撤下未经核实的弗拉门戈、波萨诺瓦、dembow、boom-bap等标签和情绪—BPM对应表。

## 1. 速度、拍子与细分（资料·定义 R01）

速度说明所指拍单位的快慢；拍子说明拍与细分的组织。4/4通常以四分音符为拍；6/8通常把六个八分音符分成两组，每组附点四分音符为拍。三连音是将某个时值三等分，不等于三拍子。

**项目归纳 R02**：常规节拍写法在 `design.rhythm` 记录：

- `pulse`：拍单位、分组及谁使其可感知；不要求必须有鼓。
- `subdivision`：二等分、三等分、十六分或摇摆等。
- `accents`：句内支点、切分、空隙和返回方式。
- `roles`：哪些声部共同落点、延续、补空、融合或形成有意对比，标到声部与拍位。

这是本项目协调声部的方法，不能扩大成所有声部必须同拍或同一重音。自由节奏、复节奏、多拍号叠置应按自身关系设计。音头靠近不自动混乱，同拍也不自动拥挤；要结合整体判断。

## 2. 鼓格（本机实现）

每个鼓件每小节 `beats_per_bar × 4` 格。默认4/4为16格，第1、5、9、13格为四个拍头；`x`普通、`X`重音、`o`轻、`.`空。每行是一个小节，鼓件用分号隔开。下面只描述位置，不按名字推出律动真实性或情绪。

| ID／拍位描述 | perc声部自编示例 |
|---|---|
| D1 每拍底鼓、2/4拍手 | `kick: x...x...x...x...; clap: ....x.......x...; hat: ..x...x...x...x.` |
| D2 底鼓1、3及3后半拍 | `kick: x.......x.x.....; snare: ....x.......x...; hat: x.x.x.x.x.x.x.x.` |
| D3 第3拍军鼓 | `kick: x...............; snare: ........x.......; hat: x.x.x.x.x.x.x.x.` |
| D4 第1/3拍底鼓、2/4拍军鼓 | `kick: x.......x.......; snare: ....x.......x...` |
| D5 含拍内底鼓 | `kick: x.....x...x.....; snare: ....x.......x...; hat: x.x.x.x.x.x.x.x.` |
| D6 不等距边击 | `kick: x..x..x...x...x.; rim: ....x.......x...` |
| D7 每拍底鼓、错位军鼓 | `kick: x...x...x...x...; snare: ...x..x....x..x.` |
| D8 不等距底鼓与边击 | `kick: x..x..x.x..x..x.; rim: x..x..x...x..x..` |
| D9 疏鼓与拍头梆子 | `taiko: X.......x.....x.; bangzi: ....x.......x...` |
| D10 密鼓与八分梆子 | `taiko: X..xX..xX..xX.xx; bangzi: x.x.x.x.x.x.x.x.` |
| D11 两次底鼓 | `kick: x.....x.........` |
| D12 末拍四次军鼓 | `snare: ............xxxx; kick: x...............` |

D3可用于探索相对于2/4反拍的半速感，这是项目应用描述，不说明它一定厚重或凶狠。D12只改变事件密度，尚未写出逐次渐强；不能把它直接称作“渐强fill”。这些位置、鼓件、力度都可修改。fill按句法与画面选择，不强制每4/8小节出现。

## 3. 摇摆概念与当前实现分开（R03/R05）

**资料·定义**：摇摆八分常用近似三连的长短关系解释；实际比例随演奏、速度与作品变化，固定2:1并非全部情况（T14）。

**本机实现**：顶层 `swing` 是当前脚本的起音后移参数，不能直接当作通用摇摆比例：

- `render_score_sf2.py`：仅普通音符分支对小节内位置小数为0.5的起音加 `swing/3` 个四分单位；不读取鼓格或VCSL分支的swing，不按比例缩短前音，不能声称整曲自动获得协调的摇摆。
- `render_score.py`：普通音符和鼓格均有半拍起音后移处理。
- 两者都不是风格真实性或真人微时值的保证。本次只纠正文档，不改变渲染行为。要求特定摆动时先验证实际事件及能力；不能核听就保留未核听。

## 4. 自编旋律节奏格（每例4个四分单位）

G4等仅占位；实际音区、音高与演奏方式需另写。名称只描述谱面，不证明推进、慵懒、悲伤或任何流派。

| ID／描述 | 例子 |
|---|---|
| N1 均匀八分 | `(G4:.5)*8` |
| N2 附点与休止 | `G4:.75 G4:.25 G4:.5 G4:.5 G4:1 r:1` |
| N3 八分弱起、跨拍延续 | `r:.5 G4:1 G4:1 G4:1 r:.5` |
| N4 四分—两八分重复 | `G4:1 G4:.5 G4:.5 G4:1 G4:.5 G4:.5` |
| N5 首拍休止 | `r:1 G4:.5 G4:.5 G4:1.5 G4:.5` |
| N6 长音加两短音 | `G4:3 A4:.5 G4:.5` |
| N7 十六分重复 | `(G4:.25)*16` |
| N8 两组三等分后长音 | `G4:1/3 A4:1/3 G4:1/3 G4:1/3 A4:1/3 G4:1/3 G4:2` |
| N9 句末休止 | `G4:1.5 A4:.5 G4:1 r:1` |
| N10 同音重复后延长 | `G4:.5 G4:.5 G4:.5 G4:.5 G4:2` |

N7不等于真实琵琶轮指或弦乐颤弓；N9的休止不保证足够给对白让位。均须结合整体与实际音源。

## 5. 自编低音候选（每例4个四分单位）

| ID／描述 | 例子 |
|---|---|
| B1 持续 | `C2:4` |
| B2 根音与五度交替 | `C2:1 G2:1 C2:1 G2:1` |
| B3 八分音与八分休止交替 | `C2:.5 r:.5 G2:.5 r:.5 C2:.5 r:.5 G2:.5 r:.5` |
| B4 均匀八分 | `(C2:.5)*8` |
| B5 不等距起音 | `C2:.75 r:.25 C2:.5 Eb2:.5 r:.5 G2:.5 Bb2:.5 C3:.5` |
| B6 一八分与两十六分的组合 | `(C2:.5 C2:.25 G2:.25)*4` |

不要凭B3认定“儿童感”，也不要凭B4认定“燃”。先试它与旋律、鼓、和声时长和音符释放的关系，再按本次目标判断。速度需注明拍单位，并与密度、重音和句长一起试定，不套情绪BPM档位。

## 6. 格式与听觉边界

6/8在本格式中的换算见 [score-format.md](score-format.md)：两主拍=60时，写 `bpm:90`、`beats_per_bar:3`，主拍支点在四分单位0与1.5，鼓格12格。字段不会自动生成分组，须落实到音符与重音。

节奏格可帮助试写，不能替代整句节奏、合奏关系和实际核听。检查器解析成功只说明格式/拍数成立，不能证明律动成立。
